# Документы задач

Каждая ветка — папка, документы внутри нумеруются с 001. Тип задачи (`feat`, `fix`, `refactor`…) записан в шапке документа, а не в пути: одна работа обычно и чинит, и добавляет, и раскладывать её по типам значит рвать один рассказ на части.

Имя папки — имя ветки без префикса: папка `kp-preview-shapes` соответствует ветке `fix/kp-preview-shapes`.

Статус в шапке говорит только о состоянии работы — `в работе` либо `влито в main`. Всё, что осталось выяснить или посмотреть, живёт в разделе «что стоит уточнить» самого документа.

Тот же порядок заведён в калькуляторе (`ekipazh-calc-frontend/docs/features`). Работа над нестандартными конструкциями идёт в обоих проектах, и часть решений здесь — перенос оттуда; документы ссылаются друг на друга по именам.
